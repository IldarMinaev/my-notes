# Server installation
## Outline
Server Ubuntu 22.04
### Prerequisites
Good for Ubuntu
```shell
sudo add-apt-repository ppa:zhangsongcui3371/fastfetch
sudo apt update
sudo apt install fastfetch net-tools ufw
```
Install docker (see [more options](https://docs.docker.com/engine/install))
```shell
# Add Docker's official GPG key:
sudo apt-get update
sudo apt-get install ca-certificates curl
sudo install -m 0755 -d /etc/apt/keyrings
sudo curl -fsSL https://download.docker.com/linux/ubuntu/gpg -o /etc/apt/keyrings/docker.asc
sudo chmod a+r /etc/apt/keyrings/docker.asc

# Add the repository to Apt sources:
echo \
  "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.asc] https://download.docker.com/linux/ubuntu \
  $(. /etc/os-release && echo "${UBUNTU_CODENAME:-$VERSION_CODENAME}") stable" | \
  sudo tee /etc/apt/sources.list.d/docker.list > /dev/null
sudo apt-get update
# Install the latest version
sudo apt-get install docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
# Add current user to docker group
sudo usermod -a -G docker $USER
# Relogin
```
### Outline self-hosted server
See [more options](https://github.com/Jigsaw-Code/outline-server/blob/master/src/shadowbox/README.md#self-hosted-installation)
Update hostname with your value
```shell
sudo bash -c "$(wget -qO- https://raw.githubusercontent.com/Jigsaw-Code/outline-apps/master/server_manager/install_scripts/install_server.sh)" install_server.sh \
  --hostname=myserver.com \
  --keys-port=443
```
Store apiUrl and certSha256.
### Configure firewall on the server
Update ports and subnets with your own values
```shell
sudo -l && (
ALLOWED_SUBNETS=(8.8.8.8/22 1.1.1.1/23)
SSH_PORT=22
HTTPS_PORT=443
ACCESS_PORT=54321
MANAGER_PORT=12345
for subnet in ${ALLOWED_SUBNETS[@]}; do
  echo Allowing $subnet
  sudo ufw allow proto tcp from $subnet to any port $SSH_PORT
  sudo ufw allow proto tcp from $subnet to any port $MANAGER_PORT
  sudo ufw allow proto tcp from $subnet to any port $ACCESS_PORT
  sudo ufw allow proto udp from $subnet to any port $ACCESS_PORT
  sudo ufw allow proto tcp from $subnet to any port $HTTPS_PORT
  sudo ufw allow proto udp from $subnet to any port $HTTPS_PORT
done
sudo ufw enable
sudo ufw status
)
```
