## Configure DNF
```bash
printf "\n%s" "countme=false" | sudo tee -a /etc/dnf/dnf.conf
printf "\n%s" "fastestmirror=True" | sudo tee -a /etc/dnf/dnf.conf
printf "\n%s" "max_parallel_downloads=10" | sudo tee -a /etc/dnf/dnf.conf
printf "\n%s" "defaultyes=True" | sudo tee -a /etc/dnf/dnf.conf
printf "\n%s" "keepcache=True" | sudo tee -a /etc/dnf/dnf.conf
```
> Для жителей РФ и СНГ параметр `fastestmirror=True` нужно попробовать включить и отключить и посмотреть как будет лучше. Некоторые пользователи заметили, что dnf пытается подключаться к серверам Yandex, а какие-то пакеты там могут отсутствовать и поэтому могут сыпаться различные ошибки.

Чистим лишнее
```bash
sudo dnf autoremove && sudo dnf clean all
```

# VirtualBox
See more installation options: https://www.virtualbox.org/wiki/Linux_Downloads
```shell
sudo dnf update
sudo rpm --import https://www.virtualbox.org/download/oracle_vbox_2016.asc
curl -s https://download.virtualbox.org/virtualbox/rpm/fedora/virtualbox.repo | sudo tee /etc/yum.repos.d/virtualbox.repo >/dev/null
sudo dnf install VirtualBox-7.1
sudo usermod -a -G vboxusers $USER
```
Restart system and update kernel-dev package
```shell
sudo dnf install kernel-devel
sudo dnf update
sudo /sbin/vboxconfig
```
Sign kernel modules
```
sudo mkdir -p /var/lib/shim-signed/mok
sudo openssl req -nodes -new -x509 -newkey rsa:2048 -outform DER -addext "extendedKeyUsage=codeSigning" -keyout /var/lib/shim-signed/mok/MOK.priv -out /var/lib/shim-signed/mok/MOK.der
sudo mokutil --import /var/lib/shim-signed/mok/MOK.der
sudo reboot
```
Disable kvm kernel extension
```shell
modprobe -c | grep kvm_intel
# alias cpu:type:x86,ven*fam*mod*:feature:*0085* kvm_intel
lsmod | grep kvm
# kvm_intel             446464  0
# kvm                  1449984  1 kvm_intel
sudo modprobe -r kvm_intel
```
Restart `rcvboxdrv setup` after system is rebooted
```shell
sudo /sbin/vboxconfig
```
