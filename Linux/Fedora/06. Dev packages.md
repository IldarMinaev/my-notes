## Configure 80 and 443 ports availability for Rancher
To allow traefik ingress controller balancing requests on basic ports, need to allow rancher open ports 80 and 443.
Run before Rancher started
```shell
sudo sysctl -w net.ipv4.ip_unprivileged_port_start=80
```
 To store the configuration of unprivileged ports permanently (after system restart) create file `/etc/sysctl.d/99-wa-for-rancher.conf` with following content
```shell
net.ipv4.ip_unprivileged_port_start=80
```

## Docker mirrors
If you have some issues on image pull, you can configure mirrors for k3s. Edit file `~/.local/share/rancher-desktop/lima/0/lima.yaml`, add following item as last elemenent into section `provision`
```shell
  - mode: system
    script: |
      #!/bin/sh
      set -eux
      mkdir -p /etc/rancher/k3s
      cat <<EOF >/etc/rancher/k3s/registries.yaml
      mirrors:
        docker.io:
          endpoint:
            - "https://dockerhub.timeweb.cloud",
            - "https://dockerhub1.beget.com",
            - "https://mirror.gcr.io",
            - "https://ghcr.io",
            - "https://quay.io",
            - "https://public.ecr.aws"
      EOF
```

# Krew
Krew is the package manager for kubectl plugins.
See available plugins: [https://krew.sigs.k8s.io/plugins/](https://krew.sigs.k8s.io/plugins/)
Make sure [[06. Dev packages#General|git installed]].
Execute for installation
```shell
(
  set -x; cd "$(mktemp -d)" &&
  OS="$(uname | tr '[:upper:]' '[:lower:]')" &&
  ARCH="$(uname -m | sed -e 's/x86_64/amd64/' -e 's/\(arm\)\(64\)\?.*/\1\2/' -e 's/aarch64$/arm64/')" &&
  KREW="krew-${OS}_${ARCH}" &&
  curl -fsSLO "https://github.com/kubernetes-sigs/krew/releases/latest/download/${KREW}.tar.gz" &&
  tar zxvf "${KREW}.tar.gz" &&
  ./"${KREW}" install krew
)
```
Create file `~/.bashrc.d/krew` with content
```shell
export PATH="${KREW_ROOT:-$HOME/.krew}/bin:$PATH"
```
Restart your shell session or run command
```shell
source ~/.bashrc.d/krew
```
Test installation
```shell
kubectl krew
```
## Some usefull kubectl plugins
* [kubectl-view-allocations](https://github.com/davidB/kubectl-view-allocations) plugin lists allocations for resources
```shell
kubectl krew install view-allocations
```
* [view-utilization](https://github.com/etopeter/kubectl-view-utilization) plugin shows cluster resource utilization
```shell
kubectl krew install view-utilization
```
* [kube-capacity](https://github.com/robscott/kube-capacity) plugin provides an overview of the resource requests, limits, and utilization
```shell
kubectl krew install resource-capacity
```
* [kubectx and kubens](https://github.com/ahmetb/kubectx) `kubectx` is a tool to switch between contexts (clusters) on kubectl faster. `kubens` is a tool to switch between Kubernetes namespaces (and configure them for kubectl) easily.
```shell
kubectl krew install ctx
kubectl krew install ns
```
* [Inspektor Gadget](https://github.com/inspektor-gadget/inspektor-gadget) is a set of tools and framework for data collection and system inspection on Kubernetes clusters and Linux hosts using [eBPF](https://ebpf.io/). It manages the packaging, deployment and execution of Gadgets (eBPF programs encapsulated in [OCI images](https://opencontainers.org/)) and provides mechanisms to customize and extend Gadget functionality.
```shell
kubectl krew install gadget
kubectl gadget deploy
kubectl gadget run trace_open:latest
```
* [Kor](https://github.com/yonahd/kor) is a plugin to discover unused Kubernetes resources.
```shell
kubectl krew install kor
```
