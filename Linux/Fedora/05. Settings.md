# Keyboard
## Свой язык в каждом окне
Setting >> Device >> Keyboard >> Input Source Switching
- Switch input sources individually for each window
## Решение проблемы с Ctrl+Shift переключением языка требующим двойное нажатие
https://forum.manjaro.org/t/have-to-press-shortcut-twice-to-change-keyboard-layout/86983
https://habr.com/ru/articles/55042/
Проверить текущие настройки:
```bash
gsettings list-recursively | grep switch-input-source
```
Tweaks >> Keyboard >> Layout >> Additional Layout Options
* Switching to another layout
	* Нужно убрать все галочки (елси таковые имеются)
Затем выполнить команду:
```bash
gsettings set org.gnome.desktop.wm.keybindings switch-input-source "['<Ctrl>Shift_L', '<Super>space']"
```
# Switch Applications and Switch Windows
Alt-Tab можно перенастроить как в винде.
```shell
gsettings set org.gnome.desktop.wm.keybindings switch-windows "['<Alt>Tab']"
gsettings set org.gnome.desktop.wm.keybindings switch-windows-backward "['<Shift><Alt>Tab']"
gsettings set org.gnome.desktop.wm.keybindings switch-applications "['<Super>Tab']"
gsettings set org.gnome.desktop.wm.keybindings switch-applications-backward "['<Shift><Super>Tab']"
gsettings list-recursively | grep -E 'switch-(applicat|windows)'
```
