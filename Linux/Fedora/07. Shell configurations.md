# Git
See documentation: https://git-scm.com/docs/git-config
## Setup git ssh identities
Generate SSH key files for each git provider. Example for Github and Gitlab:
```shell
ssh-keygen -t ed25519 -f ~/.ssh/github_ed25519
```
```shell
ssh-keygen -t ed25519 -f ~/.ssh/gitlab_ed25519
```
Configure git provider account with public SSH keys
* [Connecting to GitHub with SSH](https://docs.github.com/en/authentication/connecting-to-github-with-ssh)
* [Use SSH keys to communicate with GitLab](https://docs.gitlab.com/ee/user/ssh.html)

In next instructions change `<your_github_id>` with your Github ID
In your `~/.ssh/config`, set each ssh key for each git provider
```shell
Host github.com
    HostName github.com
    User git
    IdentityFile ~/.ssh/github_ed25519
    IdentitiesOnly=yes
Host gitlab.com
    Hostname gitlab.com
    User git
    IdentityFile ~/.ssh/gitlab_ed25519
    IdentitiesOnly=yes
```
## Setup dynamic git user email & name depending on repository url
In your `~/.gitconfig.personal`, add your personal user information
```shell
[user]
	email = <your_personal_mail>
	name = <your_github_id>
```
In your `~/.gitconfig.professional`, add your professional user information
```shell
[user]
	email = <your_professional_mail>
	name = <your_github_id>
	signingkey = <configured_gpg_key_id>
[commit]
        gpgsign = true
```
In you `~/.gitconfig` add following lines
```shell
# Global configuration
# Default user identity
[user]
    email = <your_personal_mail>
    name = <your_github_id>

# Personal configuration
[includeIf "hasconfig:remote.*.url:https://github.com/<your_github_id>/**"]
    path = ~/.gitconfig.personal
[includeIf "hasconfig:remote.*.url:git@github.com:<your_github_id>/**"]
    path = ~/.gitconfig.personal

# Professional configuraiton
[includeIf "hasconfig:remote.*.url:https://github.com/<your_github_id>/qubership**"]
    path = ~/.gitconfig.professional
[includeIf "hasconfig:remote.*.url:git@github.com:<your_github_id>/qubership**"]
    path = ~/.gitconfig.professional
[includeIf "hasconfig:remote.*.url:https://github.com/Netcracker/**"]
    path = ~/.gitconfig.professional
[includeIf "hasconfig:remote.*.url:git@github.com:Netcracker/**"]
    path = ~/.gitconfig.professional
```
# Configure GitHub to sign commits
Install gpg
```shell
sudo dnf install gpg
```
Generate gpg key (see <https://docs.github.com/ru/authentication/managing-commit-signature-verification/generating-a-new-gpg-key>)
```shell
gpg --full-generate-key
```
Get new gpg key long ID
```shell
gpg --list-secret-keys --keyid-format=long
```
Export new gpg key public key
```shell
gpg --armor --export <key-id>
```
Add the GPG key to your GitHub account (see <https://docs.github.com/en/authentication/managing-commit-signature-verification/adding-a-gpg-key-to-your-github-account>).
Configure git client to sign commits with gpg (see <https://docs.github.com/ru/authentication/managing-commit-signature-verification/signing-commits>).
Add to your git configuration:
```txt
[user]
        signingkey = <key-id>
[commit]
        gpgsign = true
```
To sign commits add `-S` argument to your command
```shell
git commit -S -m "YOUR_COMMIT_MESSAGE"
```
Do not forget to use Conventional Commits format for commit messages: <https://www.conventionalcommits.org/en/v1.0.0/>
### Auth with Github CLI
For `gh` CLI authorization run following command and follow instructions
```shell
gh auth login
```
For refreshing auth and allow updating of workflows run following command and follow instructions
```shell
gh auth refresh -s workflow
```
# Passwords

See https://www.passwordstore.org/
Install pass
```shell
sudo dnf install pass
```
Generate a pub/secret key
```shell
gpg --full-generate-key
```
Init pass store
```shell
pass init "<KEYID_GENERATED_BY_GPG>"
```
## Configure docker to use pass
Need to install [[06. Dev packages#docker-credential-pass|docker-credential-pass]]
Edit `~/.docker/config.json` file, add following content (example)
```shell
{
	"auths": {
		"ghcr.io": {}
	},
	"credsStore": "pass"
}
```
# Aliases
## kubectl
Add to `~/.bashrc.d/aliases` file
```shell
alias k=kubectl
complete -F __start_kubectl k
```
## Default editor
Add to `~/.bashrc.d/aliases` file
```shell
export VISUAL=vim
export EDITOR="$VISUAL"
```
