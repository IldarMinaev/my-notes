# Git
See documentation: https://git-scm.com/docs/git-config
## Setup git ssh identities
Generate SSH key files for each git provider. Example for Github and Gitlab:
```shell
ssh-keygen -t ed25519 -f ~/.ssh/github_ed25519
```
```shell
ssh-keygen -t ed25519 -f ~/.ssh/gitlab_ed25519
```
Configure git provider account with public SSH keys
* [Connecting to GitHub with SSH](https://docs.github.com/en/authentication/connecting-to-github-with-ssh)
* [Use SSH keys to communicate with GitLab](https://docs.gitlab.com/ee/user/ssh.html)
In your `~/.ssh/config`, set each ssh key for each git provider
```shell
Host github.com
    HostName github.com
    User git
    IdentityFile ~/.ssh/github_ed25519
    IdentitiesOnly=yes
Host gitlab.com
    Hostname gitlab.com
    User git
    IdentityFile ~/.ssh/gitlab_ed25519
    IdentitiesOnly=yes
```
## Setup dynamic git user email & name depending on repository url
In your `~/.gitconfig.personal`, add your personal user information
```shell
[user]
	email = ildar.minaev@gmail.com
	name = IldarMinaev
```
In your `~/.gitconfig.professional`, add your professional user information
```shell
[user]
	email = ildar.minaev.qubership@gmail.com
	name = IldarMinaev
```
In you `~/.gitconfig` add following lines
```shell
# Global configuration
# Default user identity
[user]
    email = ildar.minaev@gmail.com
    name = IldarMinaev

# Personal configuration
[includeIf "hasconfig:remote.*.url:https://github.com/IldarMinaev/**"]
    path = ~/.gitconfig.personal
[includeIf "hasconfig:remote.*.url:git@github.com:IldarMinaev/**"]
    path = ~/.gitconfig.personal

# Professional configuraiton
[includeIf "hasconfig:remote.*.url:https://github.com/Netcracker/**"]
    path = ~/.gitconfig.professional
[includeIf "hasconfig:remote.*.url:git@github.com:Netcracker/**"]
    path = ~/.gitconfig.professional
```
# Passwords

See https://www.passwordstore.org/
Install pass
```shell
sudo dnf install pass
```
Generate a pub/secret key
```shell
gpg --full-generate-key
```
Init pass store
```shell
pass init "<KEYID_GENERATED_BY_GPG>"
```
