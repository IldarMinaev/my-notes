1. [[07. Shell configurations#Passwords|Configure pass storage]]
2. On your Github Account, create personal access token (PAT), see https://docs.github.com/en/packages/working-with-a-github-packages-registry/working-with-the-container-registry
3. Run command
```shell
echo -n Enter your CR_PAT:\  && read -s CR_PAT && echo && echo -n Enter your GitHub Account:\  && read GIT_NAME && echo
echo $CR_PAT | docker login ghcr.io -u $GIT_NAME --password-stdin
```
Message `Login Succeeded` expected.
4. Pull required images
```shell
docker pull ghcr.io/netcracker/jaeger-readiness-probe:main
```
