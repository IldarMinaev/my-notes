# Fonts
Configure JetBrains Mono
1. [[05. Settings#JetBrains Mono font|Install JetBrains Mono]] font on your system
2. From the **File** menu (**Code** on Mac) go to `Preferences` → `Settings`, or use keyboard shortcut Ctrl+, (Cmd+, on Mac).
3. In the **Editor: Font Family** input box type `JetBrains Mono`, replacing any content.
4. To enable ligatures, go to **Editor: Font Ligatures**, click **Edit in settings.json**, and copy this line `"editor.fontLigatures": true` into json file.
